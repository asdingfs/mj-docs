# Overview of Chapter editing tools

The Chapter editor brings your content, resources, and design controls into one workspace. Use a desktop screen to edit.

## Find your way around

| Area | What you can do |
| --- | --- |
| Top bar | Edit the Chapter title, save, preview, and publish |
| Centre canvas | Add, select, edit, and arrange content |
| Left Resources panel | Browse Creations, Academics, and Achievements |
| Right Design & Settings panel | Add blocks in Design Tools; change the selected block in Settings |

If a side panel is collapsed, use **Expand Sources** on the left or **Expand Settings** on the right.

## Add content

Open **Design Tools**. Select a tool to add its block, or drag the tool onto the canvas. Select the block to edit it and see its settings.

| Tool | A useful starting point |
| --- | --- |
| Text | Explain an experience or add a reflection |
| Image | Show a photo, sketch, or result |
| Video / Audio | Add a demonstration or recording |
| File | Provide a file for readers to open or download |
| Button | Give readers a labelled destination |
| Media + Text | Put an image beside an explanation |
| Image Grid | Show several images together |
| Image Carousel | Let readers browse images one at a time |
| Text Labels | Display short labels in a wrapping row |
| Horizontal Divider | Separate parts of the Chapter |

Use the [Resources panel](../sutd-verified-elements.md) for source records. These are separate from the blocks in Design Tools.

## Save and check your work

The editor attempts to save changes automatically. You can also select **Save**. Wait for **Saved**, then use **Preview** to inspect the layout. If saving fails or you are offline, keep the tab open and resolve the issue before leaving.

To change the whole page, select the Chapter title on the canvas to open **Canvas Settings**. Expand **Chapter Banner** to choose a wide image, adjust its **16:9** crop, and select **Use cropped image** to upload it. The **3:4** card cover is managed separately through **Edit Chapter**. See [Chapter cover and banner image](../chapter-cover-and-banner-image.md).
